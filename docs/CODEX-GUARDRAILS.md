# Codex Guardrails

Authority: ENGINEERING-CONSTITUTION.md

Codex work inside KAVEEP-DEV-AGENT must behave as professional engineering work.

## Discovery Before Change

Before creating, modifying, or referencing artifacts, discover the repository state, identify existing engineering artifacts, verify whether equivalents already exist, and extend existing artifacts whenever appropriate.

## Repository Sovereignty

Do not redefine, duplicate, or assume ownership of contracts owned by KAVEEP-CORE, KAVEEP-POLICY, KAVEEP-SIA, KAVEEP-RO, or KAVEEP-COMMAND-CENTER.

When another repository artifact is missing, document the expected integration point instead of inventing it.

## Prohibited Work

Do not add autonomous agent runtime, autonomous file editing, real repository write operations outside approved scope, shell execution features, Git commit or push automation, pull request creation automation, merging, release publishing, deployment, external API integration, operating system modification, file deletion, file movement, file rename, overwrite behavior, cleanup behavior, or destructive behavior.

## Milestone Rule

Work according to verified engineering progress, not calendar dates.

One prompt should complete one clean engineering milestone.
