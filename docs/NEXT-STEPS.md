# Next steps

KAVEEP DEV AGENT now runs as a local durable application with governance checks, indexed context retrieval, structured Engineering Brain edits, sandbox validation and repair, reviewed patches, explicit approval, journaled source apply, controlled local Git commits, per-session concurrency, DPAPI secrets, packaging, and live Node container isolation evidence.

The remaining gap to a broadly Codex-like standalone agent is execution intelligence rather than safety plumbing:

1. Add a dynamic observe/reason/tool loop that can request bounded repository search, file reads, diagnostics, and validation between model turns instead of producing one edit proposal from a fixed context bundle.
2. Add streaming interactive session UX with interruption, progress, approval prompts, and compact artifact views.
3. Live-certify Python, Go, and Rust profiles with pinned offline images and representative fixtures.
4. Add eval suites for real bug-fix, refactor, test-writing, and multi-file tasks, with quality/cost/latency baselines.
5. Add signed migration and upgrade tooling before a 1.0 release.

Push, merge, remote PR creation, release publishing, deployment, governance mutation, and autonomous approval remain outside the standalone authority boundary.
