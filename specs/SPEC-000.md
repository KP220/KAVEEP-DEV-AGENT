# Purpose

This specification defines the engineering constitution of KAVEEP-DEV-AGENT.

It establishes the mandatory engineering rules, responsibilities, lifecycle, workflow, traceability requirements, quality expectations, approval requirements, and audit principles that govern all software engineering activity within the KAVEEP ecosystem.

KAVEEP-DEV-AGENT exists to ensure that every official KAVEEP software entity is engineered before it is implemented.

---

# Scope

This specification applies to:

- KAVEEP platforms
- KAVEEP AI agents
- KAVEEP services
- KAVEEP applications
- KAVEEP plugins
- KAVEEP workflows
- KAVEEP schemas
- KAVEEP specifications
- KAVEEP engineering documentation
- KAVEEP development tools

No official KAVEEP software entity may bypass this engineering constitution.

---

# Engineering Authority

KAVEEP-DEV-AGENT is the official Software Engineering Authority of the KAVEEP ecosystem.

It does not replace:

- KAVEEP Constitution
- KAVEEP Roadmap
- KAVEEP-POLICY
- Human approval

It transforms higher-level authority into practical software engineering standards.
