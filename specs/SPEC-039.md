# SPEC-039

## Local OpenAI-Compatible Provider

Status: IMPLEMENTED_UNVERIFIED

This capability adds a zero-cost local provider adapter for a trusted local
OpenAI-compatible endpoint. It accepts only explicit HTTP(S) endpoints, stores
no secret, and remains proposal-only: all governance, sandbox, validation,
approval, and controlled-write boundaries from the preceding specifications
remain mandatory. Local endpoint reachability is reported by the doctor; it is
not implied or certified solely by configuration.
